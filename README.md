MHZALY-AI-Assistant
A multi-language voice-enabled AI assistant that uses Edge TTS for speech synthesis and Google Speech Recognition for listening to user input.
Features
 * Voice interaction using a microphone.
 * Multi-language support for Urdu, English, Spanish, Arabic, French, German, and Chinese.
 * High-quality neural voice output.
Installation
Install the required libraries using pip: asyncio, pygame, speechrecognition, and edge-tts.
